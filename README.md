# 注意力高亮

网页版小游戏体验版：玩家猜测语言模型读句子时的注意力分布，再查看热力图。

代码包含客户端、评分引擎、数据契约与测试；`board-b/` 保留 B 的完整数据管线与交付资料，`content/source-c/` 包含 C 提供的内容表。当前关卡和科普卡仍是待人工审核的技术样例，不适用于儿童正式教学或研究。

需要 Node.js 22.18+ 和 pnpm 10。运行 `pnpm install`、`pnpm dev`；验证使用 `pnpm build`、`pnpm validate:levels`、`pnpm test`。构建产物位于 `apps/web/dist/`。

游戏不设账号，不上报使用数据；进度保存在本机，家长设置可清空。注意力是线索，不代表模型的完整推理。
