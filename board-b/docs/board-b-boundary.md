# 板块 B 边界

## 本包负责

- `level.schema.json`、关卡包 Schema 与 TypeScript 类型。
- 评分、理想目标、星级和结构化反馈。
- 注意力探针校准、双模型抽取、词级聚合与质量门禁。
- 12 句真实模型 draft 技术样例。
- 每日一题的选题、投票、计数和 Fetch handler。
- 面向其他板块的接口、测试和集成文档。

## 本包不负责

- 游戏页面、热力图组件、音效和动效。
- 账号、排行榜、广告、社交或儿童个人数据。
- Serverless/KV 平台账号和线上部署。
- 12 张科普卡的最终文案与美术。
- 120 句生产题库和人工内容签核。
- 家长/课堂视图。

## 对接约定

- UI 只消费 `LevelPackage` 和 `ScoreResult`，不要依赖 Python 中间产物。
- 文案板块通过 `copyId` 替换默认反馈，不改算分与错误标签。
- 后端板块用 `DailyVoteStore` 接入自己的 KV，不修改 HTTP handler 业务规则。
- 管线板块更换模型或聚合方式时，必须整批重跑并更新 `models.lock`。
- 任何 approved 数据必须有人工审核人和日期；自动流程无权签发。
